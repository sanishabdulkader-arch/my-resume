# Edit later guide

Use this file when you want to update your details quickly.

1. Personal / resume page
   - Open index.html
   - Change the name, title, email, phone, location, GitHub link, and school details in the visible sections.

2. Bio-data page
   - Open biodata.html
   - Update the personal table, family section, and academic record.

3. Projects page
   - Open projects.html
   - Replace the project titles, descriptions, and tags.

4. Contact page
   - Open contact.html
   - Update contact information and the availability text if needed.

5. Photo
   - Save a square image as assets/photo.jpg
   - The page will use it automatically.

6. Open the website locally
   - Double-click index.html, or
   - In PowerShell: cd "C:\Users\sanis\Documents\Default Project"; python -m http.server 8000
   - Then open http://localhost:8000/
